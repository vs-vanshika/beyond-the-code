03 / Things I've built

Ideas, meet implementation.

Projects exploring machine learning, privacy-preserving systems, and software development.

PROJECT / 01

SafeSepsis

Developed a federated learning framework for early sepsis prediction using clinical data. Combined autoencoder-based feature learning with recursive fuzzy clustering and interpretable predictions.

Flower Federated Learning GRU AE RFCM LIME
PROJECT / 02

PharmaguardAI

Led a four-member team to build a pharmacogenomic risk prediction system in a 24-hour hackathon. Developed a FastAPI backend for VCF parsing and drug-response predictions, with AI-generated recommendations for six drugs.

FastAPI GPT-4o-mini Swagger Render
PROJECT / 03

SafePulse

Built a federated learning system with knowledge distillation for privacy-preserving heart disease prediction. Achieved 93.51% teacher accuracy and 92.21% student accuracy.

PyTorch Flower FedAvg Knowledge Distillation ResNet-18 MobileNetV2
PROJECT / 04

MediTrack

Developed a clinic management system for patients, doctors, appointments, prescriptions, and feedback. Implemented role-based authentication and a normalized MySQL database.

Flask MySQL HTML CSS
